Summary

Same machine top. Same non-conformance. Year after year. This article explains why wiping dust without changing the physical conditions means dust returns along the same path to the same location, and provides a repeat-finding root cause diagnosis method along with ELVONIS Four Layers solutions.

1. The Phenomenon: Same Location, Same Non-Conformance

Last year's audit report: dust on machine top. This year's audit report: dust on the same machine top. Why does the same finding keep coming back?

2. Common Misconception

"Clean more often this time." But the very fact that the finding recurs proves frequency was never the issue. "The auditor is fixated on us." But in reality, the auditor is escalating a failed corrective action—they are signaling that the CAPA addressed the symptom, not the cause. Many plants write a correction into their CAPA, but never a true preventive action.

3. Engineering Principle: Correction vs. Prevention

Repeat findings are engineering evidence that the root cause was never eliminated.

In the STADR Model, dust control has four stages: Source → Transport → Amplification → Deposition. If you only clean the Deposition stage but leave the physical conditions in Source, Transport, and Amplification unchanged, dust will simply follow the same path back to the same location. You are removing the outcome without changing the physics that produced it.

Correction addresses outcomes. Prevention addresses causes. Correction does not change physical laws. Prevention changes physical conditions.

The three most common physical root causes behind repeat findings:

A thermal plume that persists—hot equipment keeps generating upward airflow, continuously delivering dust to the same surface.

A stagnation zone that remains unbroken—low-velocity regions keep allowing particles to settle out.

A surface geometry that remains unchanged—horizontal or near-horizontal surfaces continue to act as deposition platforms.

Until these conditions are altered, increased cleaning frequency only shortens the interval between recurrences.

4. Field Verification: Three-Step Repeat Finding Diagnosis

Step one: Three consecutive days of tape testing at the same location. This confirms whether the deposition pattern is stable and ongoing—if dust returns within 24 hours at the same rate, the mechanism is active.

Step two: Pre-cleaning and post-cleaning tape comparison. This tells you whether your cleaning method actually removes particles or merely redistributes them. If post-cleaning deposition remains high, the method itself is ineffective.

Step three: Review the previous corrective action record. Ask one question: did the last CAPA identify a physical root cause, or did it only add cleaning frequency? If the latter, the root cause was never addressed.

5. Engineering Solution: Return to the ELVONIS Four Layers from Source

When a finding repeats, do not start with cleaning. Start from the top of the control hierarchy.

Layer 1 (Source): Re-examine whether any dust sources were missed. Check for leaking seals, worn components, or newly introduced materials.

Layer 2 (Airflow): Re-run smoke pencil tests to map current airflow. Has the stagnation zone shifted? Is the thermal plume still active? Adjust return grilles or supply air direction to break the pattern.

Layer 3 (Surface): Consider surface modification. Horizontal to sloped. Open to enclosed. Multiple panels to single panel. Change the geometry that allows dust to settle.

Layer 4 (Cleaning): Only after the above are addressed, implement data-driven cleaning frequency based on deposition rates—not a blanket increase.

6. Engineering Case Card

Industry: Seasoning

Finding: Mixer top dust recorded as a non-conformance for three consecutive years. Each previous corrective action was "increase cleaning frequency."

Root Cause

Thermal plume and stagnation zone were never addressed. The mixer generated a persistent thermal plume, and the surrounding airflow had a stable stagnation zone directly above the machine. Cleaning frequency was increased three times, but deposition returned at the same rate each time.

Engineering Actions

Installed a deflector to redirect the thermal plume away from the stagnation zone. Adjusted return grille direction to increase airflow across the mixer top. Replaced aging gaskets to eliminate a minor internal leakage source.

Results

Zero findings the following year. Deposition rate dropped over 80%. Cleaning frequency returned to the original schedule.

Lessons Learned

A repeat finding is a warning signal that the CAPA was correction-only. If the same location fails twice, the root cause was never eliminated. The correct response is to re-examine physical conditions, not to add more cleaning.

7. First Principle

ELVONIS Principle No.15

Repeat findings are engineering evidence that the root cause hasn't been eliminated. As long as the physical laws remain unchanged, dust will follow the same path back to the same location.

8. Engineering Takeaways

A repeat finding means correction happened without prevention.

Consecutive tape testing confirms whether the deposition pattern persists.

Review the previous CAPA to determine whether a physical root cause was identified.

Return to the Four Layers from Source—do not default to more cleaning.

Change the physics: break the plume, break the stagnation, change the surface.

一、现象：同一个位置，同一个不符合项

去年审核报告：设备顶部积尘。今年审核报告：同一设备顶部积尘。为什么？

二、常见误区

“上次擦得不够勤这次勤快点”--但重复发现本身就证明频率不是问题。把重复发现归结为“审核员盯上了”--但审核员是在升级判定纠正措施无效。CAPA只做纠正没做预防。

三、工程原理

重复发现本质是根因未被消除。在STADR模型中，只清理“沉积”阶段但不改变“尘源”“迁移”“放大”阶段的物理条件，粉尘会沿相同路径回到相同位置。纠正处理结果，预防处理原因。纠正不改变物理规律，预防改变物理条件。

三个最常见物理根因：热羽流持续存在、气流停滞区未被打破、表面形态未改变。

四、现场验证方法

连续三天胶带测试确认沉降模式是否持续。清洁前后胶带对比确认清洁方法是否有效。回顾上次纠正措施判断根因是否已被识别。

五、工程解决方案

回到四层控制架构从源头重新分析：检查是否有遗漏尘源，烟雾笔重新测试气流状态，考虑表面形态改造，最后才增加基于数据的清洁频次。

六、工程案例卡片

行业：调味品。搅拌缸顶部连续三年审核被开不符合项。每次纠正措施都是“增加清洁频率”。根因：热羽流和气流停滞区从未被处理。措施：安装导流板，调整回风口方向，更换老化密封垫圈。结果：次年零发现，沉降量下降超80%。

经验教训：重复发现是CAPA无效的警示信号。

七、第一性原理

ELVONIS第一性原理第十五条：重复发现是根因未被消除的工程证据。只要物理规律不变，粉尘就会沿相同路径回到相同位置。

八、工程要点总结

重复发现说明只纠正未预防。连续胶带测试可确认沉降模式是否持续。回到四层控制架构从源头重新分析。
